# 🥤 Restock Calculator

A simple, fast, and mobile-friendly web app to help restock vending machines. Just input the current stock for each drink, and the app instantly calculates exactly how many units you need to bring.

---

## 🚀 Features

- **Quick Calculations:** Calculates restock amounts (`Max Capacity - Current Stock`).
- **All Default Beverages Included:**
  - **Coke** (Max: 30)
  - **Diet Coke, Coke Zero, Fanta, Sprite, Sprite Zero** (Max: 15)
  - **Cherry Coke, Vitamin Water, Gold Peak** (Max: 10)
  - **SmartWater** (Max: 20)
  - **Dasani** (Max: 25)
- **One-Tap Quick Actions:**
  - **Fill All:** Sets all stock inputs to max capacity.
  - **Clear:** Resets all inputs to 0.
- **Mobile Optimized:** Large input fields and buttons designed for single-handed phone use.
- **Works Offline:** Built with plain HTML, CSS, and JavaScript—no frameworks or external libraries needed.
